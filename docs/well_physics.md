# The Well physics reference

The project now imports a real trajectory from
[PolymathicAI/the_well](https://github.com/PolymathicAI/the_well), pinned at commit
`aac88c0b5eb9cbe4b7b2797eaaa550a43706fb44`. A local source checkout is under ignored
`runs/vendor/the_well/`. The integration follows its Cartesian HDF5 data specification.

The Well is a collection of recorded numerical simulations and surrogate benchmarks. It is not
a replacement for Unreal Chaos or a general interactive PDE solver. The first integration uses
recorded gas mixing with radiative cooling, generated by Athena++. It does not represent brine,
ice fracture, magma rheology or a new coupled planetary simulation.

## Prepared reference

```powershell
uv run python -m xeno.cli well-prepare
```

This fetches only one 79,459,648-byte file from `turbulent_radiative_layer_2D/test`, checks its
pinned SHA-256, and extracts trajectory 0. `configs/well_sources.json` records the exact URL,
checksum, source commit, citation and licence. The loader reads bounded strided HDF5 selections;
it does not load or download the full collection.

The source has 101 frames at 128 by 384 cells. The initial display export selects every second
frame and spatial strides 2 and 6, giving 51 frames at 64 by 64. Original coordinates and times
are retained. Density uses a documented 8-bit display normalization; velocity components use
signed 16-bit display quantization with a retained physical scale. Those approximations are for
visualization, not scientific evaluation or conservation measurements.

Artifacts:

- `runs/well/turbulent_radiative_layer_tcool_0.32.hdf5`: verified original file.
- `runs/well/reference-field.json`: bounded Unreal playback data.
- `runs/well/reference-field.manifest.json`: provenance, ranges, strides and export checksum.

The launcher attaches this field automatically when present. In Unreal, **P** toggles a labelled
reference patch showing density as normalized height/color and velocity as directional arrows.
Its playback loops over 20 wall-clock seconds; source time uses dimensionless simulation units.
It remains separate from F0 observations, chemistry, budgets, samples and mission time. Switching
the artistic scenario changes the presentation around the same reference; it does not reinterpret
the astrophysical gas trajectory as liquid water or lava.

## Advancing beyond replay

The Well source links the generation codes for each dataset. New physical trajectories require
the appropriate solver, initial/boundary conditions and numerical checks. For example,
`rayleigh_benard` and `shear_flow` link to Dedalus generation scripts. That solver is not installed
or validated by this integration. A trained surrogate also needs an explicitly validated checkpoint;
the scene planner does not substitute predicted data for recorded fields.

The pinned source notes an October 2026 shear-flow split correction, with the Hugging Face copy
still on the older version at the time inspected. No model training or holdout claims are made here.
